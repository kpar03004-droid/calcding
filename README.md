# 칼띵 (CalcDing)

**띵타이쿤 세레니티 전문가 수익 계산기**

인벤토리와 상자를 읽어 재료를 자동으로 세고, 내 강화·스킬·각인 수치로
재배·채광·해양·사냥의 **예상 수익**을 계산해 줍니다.

마인크래프트 **1.21.4** · **Fabric / NeoForge** · 클라이언트 전용

**운영진 승인 완료 (2026-08-20)**

### **[▶ 최신 버전 받기](../../releases/latest)**

위 링크에서 쓰시는 로더에 맞는 파일 **하나만** 받으세요.

| 로더 | 파일 |
|---|---|

| **NeoForge** | `calcding-*-neoforge.jar` |

## 📥 설치

1. 기존 칼띵 파일이 있으면 mods 폴더에서 **삭제**하세요. (안 지우면 충돌)
2. 받은 파일을 `.minecraft/mods` 에 넣으세요. (로더에 맞는 것 하나만)
3. 게임을 **완전히 종료했다가 다시 실행**하세요.

기존 설정·저장한 상자는 그대로 유지됩니다.
클라이언트 전용이라 서버에는 넣지 않으셔도 됩니다.

---

## 🕹️ 기본 사용법

- 채팅에 **`/칼띵`** — 또는 **설정 > 조작키 > 칼띵** 에서 원하는 키를 지정
  (다른 모드와 안 겹치게 기본 미할당입니다)
- **처음 한 번만** 설정 탭에서 도구 강화 단계·전문가 스킬·각인 레벨을 넣어주세요.
  그 뒤로는 모든 탭이 그 값으로 계산합니다.

| 탭 | 하는 일 |
|---|---|
| **계산** | 사칙연산 계산기 · 대리 판매 정산(수수료 역산) |
| **재배** | 오늘 추천 · 요리 계산 · 일일 수확 |
| **채광** | 일일수익 · 가공수익 · 세공 |
| **해양** | 일일수익 · 계산기 · 수족관 |
| **사냥** | 전리품 · 영혼 계약서 · 각인석 조사 · 육식동물 · 공룡 |

**상자도 같이 셉니다.** 상자를 직접 우클릭해서 열면 오른쪽 위에 라벨 칸과 `[저장]` 이 뜹니다.
이름 지어 저장하면 그 상자 내용이 계산에 합산됩니다.

**시세는 알아서 채워집니다.** 유저상점·플리마켓·NPC 상점을 열면 거기 보이는 가격을 그대로 읽습니다.
값이 바뀌는 게 싫으면 가격칸 왼쪽 **압정**을 누르세요.

> 자세한 사용법은 릴리스에 첨부된 **설명서**를 봐주세요.

## 🪞 서버 규정에 대해

**"거울이지 망원경이 아니다"** — 이미 내 화면에 보이는 것만 읽습니다.

- 게임 서버로 **아무것도 보내지 않고 받아오지도 않습니다**
- 상자는 **내가 직접 우클릭해서 연 바닐라 저장 블록**만 읽습니다 (서버 상점·거래 GUI 안 건드림)
- 자동 조작 없음 — 계산과 표시만 합니다
- 다른 플레이어 정보에 접근하지 않습니다
- 유일한 바깥 통신은 **새 버전 확인**입니다. 접속할 때 깃허브의 정해진 파일을 한 번 읽는 것이
  전부이고 내 정보는 담기지 않습니다. 설정에서 끌 수 있습니다.

계산에 쓰는 수치(도구 강화표·스킬 효과·각인 확률)는 공식 위키에 공개된 값이며,
모드는 그것으로 산수를 대신해 줄 뿐입니다.

제작 전 1:1 문의로 **"계산기 모드의 기능은 제작이 가능합니다"** 답변을 받고 만들었습니다.

## 📌 알아두실 것

- 계산값은 **기댓값**입니다. 확률이 걸린 항목은 실제와 차이가 납니다.
- 시세가 안 채워진 항목은 순수익이 안 나옵니다. 해당 상점을 한 번 열어주시거나 직접 넣어주세요.
- **플로리스트(향장품)는 아직 없습니다.** 꽃 등급 확률과 향장품 제작 산출량이 공식으로
  공개되지 않아, 추정값으로 계산하면 틀린 답을 자신 있게 보여주게 되기 때문입니다.
